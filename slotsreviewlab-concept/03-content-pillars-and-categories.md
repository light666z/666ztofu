# 03 — Content Pillars & Categories

## Content model

Use a **hub-and-spoke** model:

- **Pillar (hub)** = broad, evergreen Korean guide
- **Cluster (spoke)** = focused reviews, explainers, comparisons that link back to the hub

Target for first 90 days: establish **4 pillars**, publish supporting clusters, and keep category taxonomy stable.

---

## Four content pillars

### Pillar 1 — 슬롯 기초 랩 (Slot Fundamentals Lab)
**Purpose:** Make Korean beginners literate in core concepts.  
**Hub idea:** `슬롯 게임 완전 가이드: 용어부터 평가 기준까지`

Cluster examples:
- RTP란 무엇인가
- 변동성(Volatility) 읽는 법
- 페이라인 / 웨이즈 / 메가웨이즈 차이
- 보너스 구매(Buy Bonus) 기능의 의미와 리스크
- 슬롯 용어 사전 (KR)

### Pillar 2 — 게임 리뷰 (Game Reviews)
**Purpose:** Consistent, criteria-based reviews of individual titles.  
**Hub idea:** `slotreviewlab 리뷰 기준과 점수 체계`

Cluster examples:
- Individual game reviews (인기/대표 타이틀 중심)
- “초보 추천 후보” vs “하이 리스크 취향” segmented reviews
- Remaster / sequel comparison reviews

### Pillar 3 — 프로바이더 & 유형 분석 (Providers & Types)
**Purpose:** Help readers understand studios and game styles.  
**Hub idea:** `슬롯 프로바이더와 게임 유형 이해하기`

Cluster examples:
- Provider overview posts
- Classic vs video vs megaways style comparisons
- Feature deep-dives (프리게임, 멀티플라이어, 클러스터 페이 등)

### Pillar 4 — 안전·책임·한국 맥락 (Trust, Responsibility, KR Context)
**Purpose:** Build long-term trust and genuine value for Korean readers.  
**Hub idea:** `한국 독자를 위한 슬롯 정보 이용 가이드`

Cluster examples:
- Responsible play basics
- Common scam / fake-review patterns
- How to read promotional claims critically
- What information this site will and will not provide

| 랩 노트 | `/lab-notes/` | Editorial / methodology / updates |

### Category rules
- Every post belongs to **one primary category**
- Optional secondary tags for themes (`초보`, `고변동성`, `프리스핀`, provider name)
- Do not create a new category until an existing one is clearly overloaded

## Review scoring framework (shared across Pillar 2)

Use a 5-dimension score (each 1–5), then a weighted total:

| Dimension (KR) | What it measures | Weight |
|----------------|------------------|--------|
| 테마/비주얼 | Theme clarity, art, audio cohesion | 20% |
| 플레이 루프 | Core spin experience and pacing | 25% |
| 보너스 설계 | Feature quality and readability | 25% |
| 변동성 적합성 | Whether volatility is clearly communicated / fitting stated style | 15% |
| 초보 친화성 | How easy it is for newcomers to understand | 15% |

Rules:
- Always show dimension scores, not only a final number
- State data limits (e.g., published RTP if known; otherwise “미확인/공식 정보 부족”)
- Separate **facts** from **taste judgments**

## Topic selection filter

A topic is approved only if it passes all four:

1. **Audience fit** — useful to Korean readers in this niche
2. **Brand fit** — strengthens “review lab” identity
3. **Differentiated value** — not empty affiliate rewrite
4. **Ethical fit** — no illegal-instruction or guaranteed-win framing

SEO opportunity is a bonus, not the sole reason to publish.
