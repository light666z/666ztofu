## Keyword classes (how we use terms)

| Class | Meaning | Traffic expectation |
|-------|---------|---------------------|
| **Primary SEO keyword** | Main organic target for a URL / category cluster | Treat as a search-led opportunity when evidence supports it |
| **Secondary / long-tail** | Supporting phrases; may appear in titles, H2s, or variants | Helpful, not the main traffic bet |
| **Editorial topic** | Publish for reader value / positioning | **Keep in content strategy**; **not** a major organic traffic driver |

Low-search editorial topics are **not removed** from content plans—they simply are not labeled as primary SEO targets.

## Guardrails (from positioning + brand safety)

**Target intents we want:** informational discovery / evaluation.  
**Avoid as primary SEO targets:**

| Rejected keyword pattern | Why |
|--------------------------|-----|
| `고배당 슬롯 추천`, `맥스윈 높은 슬롯` | Recommendation driven by payout potential |
| `필승`, `확정 수익`, `잘 터지는 슬롯` | Win/probability hype |
| `슬롯사이트 추천`, `안전 놀이터`, `여기서 플레이` | Operator funnel (Phase 2 undecided) |
| `RTP 높은 슬롯 추천` as *the* hook | Specs may be facts; must not lead the pitch |
| Unrelated trending keywords solely for traffic | No low-value/unrelated SEO bait |
| Bare `슬롯 추천` as primary | Commercial SERP overlap; avoid as primary SEO target |

**Stuffing rule:** One clear primary intent per URL. Natural Korean titles/metas only.

## Category SEO map

### 1) 슬롯 리뷰 (`reviews`) — mostly **search-led**

**Demand note (qualitative, no MSV):** Game-name + 리뷰 patterns show the strongest open-web targeting evidence among our set, especially for well-known titles. Demand is **title-dependent**.

| Class | Keyword | Intent |
|-------|---------|--------|
| **Primary SEO** | `{게임명} 리뷰` | Informational (SERP often mixed commercial) |
| **Primary SEO** | `{게임명} 슬롯 리뷰` | Informational |
| **Relevant variant** (use when KR name is commonly searched/recognized) | `{한국어명} 리뷰` | Informational |
| Secondary / long-tail | `{게임명} 테마`, `{게임명} 보너스 구매`, `{게임명} 연출`, `{게임명} 특징`, `{게임명} 그래픽` | Informational |

**Channel lean:** Mainly search-led once titles are chosen; internal links support lesser-known games.

### 2) 슬롯 가이드 (`guides`) — **mixed**

**Demand note (qualitative, no MSV):** `슬롯 보너스 구매` has clearer content-supply evidence than taste-discovery phrases. Keep experience/pacing angle (not EV/bankroll strategy).

| Class | Keyword | Intent |
|-------|---------|--------|
| **Primary SEO** | `슬롯 보너스 구매` | Informational |
| **Primary SEO** | `슬롯 고르는 법` | Informational |
| **Secondary / long-tail** | `보너스 구매란` | Informational |
| Secondary / long-tail (also useful) | `보너스 구매 경험`, `Buy Feature 의미`, `슬롯 사운드 평가`, `슬롯 피처 보는 법`, `초보 슬롯 용어` | Informational |
| **Editorial topic** (publish for value; not a primary SEO bet) | `흥미로운 슬롯 찾는 법` | Informational / brand teaching |

**Note on Post 01:** Working title `흥미로운 슬롯 찾는 법: …` remains valid as **editorial/content** (locked in `03`). It is **not** promoted here as a primary organic traffic keyword.

**Channel lean:** Feature/definition guides lean search; taste/editorial guides lean on-site + share.

### 3) 슬롯 발견 (`discover`) — mainly **internal / social / browse-led**

**Demand note (qualitative, no MSV):** Pair comparisons and “비교” language have some targeting evidence; presentation-led list phrases look weaker as head search terms. Do not chase payout “추천” SERPs.

| Class | Keyword | Intent |
|-------|---------|--------|
| **Primary SEO** (topic/pair dependent) | `{게임 A} vs {게임 B}` | Informational |
| **Primary SEO** (topic dependent) | `슬롯 비교` | Informational |
| Secondary / long-tail | `시각적으로 독특한 슬롯`, `보너스 구매 있는 슬롯 모음` (experience framing), `사운드 좋은 슬롯` | Informational |
| **Editorial topic** (publish for value; not a primary SEO bet) | `연출 좋은 슬롯` | Informational |

**Channel lean:** Mainly internal discovery + shares; search is secondary.

## Title pattern formulas (voice-matched)

Still valid for both SEO-led and editorial posts:

1. `{게임명} 리뷰: {경험 각도 질문}`
2. `{개념}이란? {경험 관점 한 줄}` — fine for secondary/`보너스 구매란` style
3. `{발견 행동}: {취향/감각 기준}` — fine for **editorial** guides (e.g. Post 01)
4. `{게임 A} vs {게임 B}: {어떤 감각이 맞을까}`
5. `{감각 형용사} 슬롯 모음: {구체적 경험 각도}` — fine for **editorial** discover pieces

**Avoid in titles:** 필승, 대박, 지금 바로, 공식 1위, 수익 보장, 사이트 추천 CTAs.

## Meta description rules

| Rule | Guidance |
|------|----------|
| Length band | **약 70–110자** (Korean, spaces included) — display heuristic only; **not** a volume claim |
| Voice | Calm, specific, experience-led; one reader job |
| Must include | What the page helps decide/understand |
| Must avoid | Win guarantees, FOMO, operator CTAs, stuffing, absolute “최고” |
| Specs | Optional context only — never the sales hook |
| Brand | Optional `| 슬롯리뷰랩` if natural |
