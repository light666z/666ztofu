## Guardrails (from positioning + brand safety)

**Target intents we want:** informational discovery / evaluation (“interesting?” “what does this feature feel like?”).  
**Avoid as primary targets** (fight positioning or DO/DON’T):

| Rejected keyword pattern | Why |
|--------------------------|-----|
| `고배당 슬롯 추천`, `맥스윈 높은 슬롯` | Recommendation driven by payout potential |
| `필승`, `확정 수익`, `잘 터지는 슬롯` | Win/probability hype |
| `슬롯사이트 추천`, `안전 놀이터`, `여기서 플레이` | Operator / where-to-play commercial funnel (Phase 2 undecided; not Phase 1 SEO lead) |
| `RTP 높은 슬롯 추천` as *the* hook | Specs may appear as facts; must not lead the pitch |
| Unrelated trending keywords solely for traffic | Brand-safety: no low-value/unrelated SEO bait |

**Stuffing rule:** One clear primary intent per URL. Titles/metas use natural Korean; no comma-stuffed keyword lists.

## Category SEO map

### 1) 슬롯 리뷰 (`reviews`) — mostly **search-led** (game-name queries)

**Honest demand note (estimate):** `{게임명} 리뷰` / `{게임명} 슬롯` style queries are the clearest search path. KR SERPs for these often mix affiliate “play here” pages with feature write-ups — we compete on **experience depth**, not casino CTAs.

| Type | Keyword ideas | Intent |
|------|---------------|--------|
| **Primary (pick 1–2 per post)** | `{게임명} 리뷰` | Informational (often mixed commercial SERP) |
| **Primary alternate** | `{게임명} 슬롯 리뷰` | Informational |
| **Primary when KR name common** | `{한국어 게임명} 리뷰` (+ EN title on-page) | Informational / brand-of-game |
| Long-tail | `{게임명} 테마`, `{게임명} 보너스 구매`, `{게임명} 연출`, `{게임명} 특징`, `{게임명} 그래픽` | Informational |

**Channel lean:** **Mainly search-led** once specific titles are chosen. Internal links + discover hubs support discovery when the game name isn’t searched yet.

### 2) 슬롯 가이드 (`guides`) — **mixed**; concept explainers search-led, taste-discovery thinner

**Honest demand note (estimate):** Terms like `보너스 구매`, `보너스 바이`, `Buy Feature` show up in KR content ecosystems, but many top results are **strategy / bankroll / EV** angled — we must keep the **experience/pacing** angle (brand safety). Broader “취향으로 슬롯 고르기” style queries look **thinner** and more educational/browse — good for brand teaching, weaker as raw volume plays (**estimate**).

| Type | Keyword ideas | Intent |
|------|---------------|--------|
| **Primary candidates** | `보너스 구매란` / `슬롯 보너스 구매` | Informational |
| **Primary candidates** | `슬롯 고르는 법` / `흥미로운 슬롯 찾는 법` | Informational |
| **Primary candidates** | `슬롯 연출` / `슬롯 테마` (as evaluation language) | Informational |
| Long-tail | `보너스 구매 경험`, `Buy Feature 의미`, `슬롯 사운드 평가`, `슬롯 피처 보는 법`, `초보 슬롯 용어` | Informational |

**Channel lean:** **Mixed** — feature-definition guides lean search; taste/discovery guides lean **on-site + share/community**, with search as secondary (**estimate: thin pure volume**).

---

### 3) 슬롯 발견 (`discover`) — mainly **social / internal / browse-led**

**Honest demand note (estimate):** Experience-angled multi-game queries (`연출 좋은 슬롯`, `테마별 슬롯 추천` without payout framing) are easy to *write*, but KR search demand often collapses into **고배당/사이트 추천** SERPs. Winning “volume keywords” here would fight positioning — so we **do not** chase those. Treat discover as library UX + shareable lists, with light long-tail capture.

| Type | Keyword ideas | Intent |
|------|---------------|--------|
| **Primary candidates** | `슬롯 추천` **only if** title/body clearly mean experience/taste — risky overlap with commercial SERPs | Informational (SERP often commercial) |
| **Safer primary** | `슬롯 비교` / `{게임 A} vs {게임 B}` | Informational |
| **Safer primary** | `테마 다른 슬롯` / `연출 좋은 슬롯` | Informational (**estimate: thin**) |
| Long-tail | `시각적으로 독특한 슬롯`, `보너스 구매 있는 슬롯 모음` (experience framing), `사운드 좋은 슬롯` | Informational |

**Channel lean:** **Mainly social/community + internal discovery** (from reviews/guides). Search is a bonus, not the reason to publish.

## Title pattern formulas (voice-matched)

Calm, playful-academic, non-hype, non-absolute — aligned with `04-voice-brand-safety.md`:

1. `{게임명} 리뷰: {경험 각도 질문}`  
   ex) `… 리뷰: 연출·테마가 경험을 잡아끄는가`
2. `{개념}이란? {경험 관점 한 줄}`  
   ex) `보너스 구매란? 경험 관점에서 읽는 법`
3. `{발견 행동}: {취향/감각 기준}`  
   ex) `흥미로운 슬롯 찾는 법: 테마·연출·피처로 내 취향에 맞는 게임 고르기`
4. `{게임 A} vs {게임 B}: {어떤 감각이 맞을까}`  
   — comparison without “누가 더 고배당”
5. `{감각 형용사} 슬롯 모음: {구체적 경험 각도}`  
   ex) `첫인상으로 고르는 슬롯: 시각·테마가 다른 3작품`

**Avoid in titles:** 필승, 대박, 지금 바로, 공식 1위, 수익 보장, 사이트 추천 CTAs.

## Meta description rules

| Rule | Guidance |
|------|----------|
| Length band | **약 70–110자** (Korean, spaces included) — **estimate** for typical KR SERP truncation; write the promise in the first ~70자 |
| Voice | Calm, specific, experience-led; one reader job |
| Must include | What the page helps decide/understand (interesting / how it feels / how to evaluate) |
| Must avoid | Win guarantees, FOMO, operator CTAs, keyword stuffing, absolute “최고” claims |
| Specs | RTP/max win only as optional context — never the sales hook |
| Brand | Optional short `| 슬롯리뷰랩` only if it fits naturally without stuffing |

**Pattern:** `{독자 과제 한 줄}. {경험 각도 한 줄}. {과한 약속 없이 닫기}.`
